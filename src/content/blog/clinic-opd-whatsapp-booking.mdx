Clinic reception in Vizag spends a large part of the day on the same calls: is there a slot tomorrow, can I change my time, is the report ready? WhatsApp can take the booking work off the phone, without giving medical advice.

## What patients should be able to do

A useful clinic WhatsApp flow lets a patient:

- see open OPD slots for a doctor or department,
- book or change a slot,
- get a reminder the evening before,
- get a message when a report is ready.

It should not diagnose, suggest medicines, or promise results. Those stay with the doctor.

## What the clinic needs first

Automation needs a clean diary:

- doctor name and OPD days,
- slot length,
- which slots are already taken,
- patient phone number on WhatsApp.

If the diary still lives only in a paper register, digitise that first. WhatsApp cannot book what the software cannot see.

## How reception stays in control

Every booking should appear in one list for reception. Staff can move a slot, block a holiday, or ask the patient to call when the request is unusual.

Patients should always be able to ask for a person. The assistant is for routine booking, not for emergencies or complaints.

## A small first version

Start with one doctor or one department. Run it for two weeks. Watch how many calls drop and how many bookings need a human change. Then add the next doctor.

Clinics in Visakhapatnam that already use WhatsApp for reports can use the same official number for OPD booking, so patients are not talking to a new unknown contact.
