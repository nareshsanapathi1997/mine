Coaching admissions looks small until two counsellors answer the same parent. One says the batch is open. The other says the fee was already discussed. Both are looking at different chats. The institute does not have an admissions process so much as a set of memory aids.

Automation helps when you treat that process as a sequence with a single record, and when you are honest about which steps a person must still own.

## The path you already run

Most desks repeat the same chain, even if it is not written down.

- A parent asks about a course, usually on WhatsApp or a website form.
- Someone sends the timing, the fee and what documents are needed.
- The family applies, or goes quiet.
- A counsellor follows up.
- A fee is recorded and a batch is assigned.
- Reminders go out before the batch starts.

Every break in that chain is a place where the status lives only in one person’s phone. The parent then calls the front desk, and the front desk calls the counsellor, and the answer depends on who picks up.

## Write the status down before you buy a tool

Agree the statuses in plain language. New enquiry. Waiting on documents. Offered a batch. Fee pending. Joined. Closed, with a reason. If two people cannot point at the same list, software will only preserve the argument.

Decide which fields are required before a status can change. A “joined” student without a batch is not a status. It is a gap that the next reminder will expose.

This list is the product. The website form, the WhatsApp reply and the counsellor’s screen are views of it.

## What is worth automating first

Start with messages that do not require a judgment.

A parent asking “what is the status of my application?” can be answered from the record, by a person or by an assistant that is only allowed to read it. A reminder the day documents are still missing can be sent from that same status. A note the day before a batch starts can go to everyone who is marked joined.

Those three remove a large share of the repeated typing without deciding who deserves a seat.

Follow-up tasks are the next step. When an enquiry sits in “waiting on documents” for longer than you consider reasonable, create a task for the counsellor who owns it. The task should show the last message, not a naked name and phone number.

## What should stay with a counsellor

Fee concessions, batch changes after a complaint, and the conversation about whether a course is even the right fit are not workflows to force through. They are the reason the institute has staff. The system should make the exception visible: who asked, what was decided, and what the parent was told.

An assistant that invents a discount, or promises a batch that is already full, creates more repair work than it saves. Limit it to the statuses and the public course facts you have written down. When the question leaves that list, the handoff goes to the counsellor with the history attached.

## Where the channels meet

Parents will not move to a portal just because you built one. Keep WhatsApp if that is where they already write. The change is that the chat updates the admissions record, and the record is what the next counsellor sees.

The website form should create the same kind of enquiry, with the course already filled in. Otherwise the site and the chat are two funnels that merge only at the end of the day, in someone’s notes.

A simple dashboard is the counsellor view: who is waiting, which batch is filling, which follow-ups are due. It does not need to be a second product. It needs to read the record everyone else is updating.

## A rollout that does not stop the desk

Pick one course or one upcoming batch. Run the new record beside the old sheet for that batch only, until the statuses match what the counsellors believe is true. Then turn on one automated message, not five. Read the replies. Fix the wording. Add the next message when the first one is dull and reliable.

Dull is the goal. Admissions automation is working when a parent gets the same status whoever they ask, and a counsellor spends time on the families that actually need a conversation.
